# URBAN CLOSET（アーバンクローゼット）公式オンラインストア

**コンセプト**：「都市で生きる人の、新しいワードローブ」  
**シーズン**：`2026 SPRING COLLECTION`

ストリートの自由な空気感と建築的なミニマリズムを融合させた、ユニセックスアパレルブランド **「URBAN CLOSET」** の全6ページ構成・公式EC風Webサイトです。

---

## 1. すぐに確認する方法（ローカル閲覧ガイド）

特別なプログラムのインストールやサーバー構築をしなくても、フォルダ内の **`index.html`** をパソコン上でダブルクリックするだけで、そのままブラウザで全6ページの遷移・絞り込み・ミニカート追加・ライトボックス拡大などを確認できます。

## 3. オーナー様向け かんたん編集ガイド

各ファイルの変更しやすい場所には `<!-- ★... -->` や `/* ★... */` という**日本語の目印（コメント）**を入れています。

### ① 商品の名前・価格・サイズ表・写真を変えたいとき
- **[`js/products-data.js`](./js/products-data.js)** をメモ帳やエディタで開きます。
- `products` の中にある `name`（商品名）、`price`（価格）、`images`（3枚の写真URL）、`sizeGuide`（実寸サイズ表）を書き換えて保存するだけで、**TOPページ・商品一覧・商品詳細・検索結果・ミニカートのすべてに自動で一括反映**されます。
- 送料無料になる基準金額（初期設定：`15000` 円）も、同じファイル先頭の `freeShippingThreshold` で変更できます。

### ② サイト全体の色味を調整したいとき
- **[`css/style.css`](./css/style.css)** の一番上にある `:root` ブロック内の4つのカラー変数を変更すると、全6ページの色がまとめて切り替わります。
  - `--color-white: #FFFFFF;`（背景ホワイト）
  - `--color-black: #0A0A0A;`（文字・メインボタンのディープブラック）
  - `--color-gray: #6B7280;`（補足文字のニュートラルグレー）
  - `--color-light-gray: #F9FAFB;`（背景切り替え用のライトグレー）

### ③ お問い合わせフォームの「返信目安日数」を変えたいとき
- **[`contact.html`](./contact.html)** を開き、`通常2〜3営業日以内` と書かれている2箇所（送信ボタンすぐ下の補足文と、送信完了メッセージ内）をお好みの日数に書き換えてください。

## 4. 実装されている主な機能・品質設計

- **全ページ保持の右スライド式ミニカート**：`localStorage`（ブラウザの一時保存領域）を活用しているため、別ページへ移動してもカートの中身とヘッダー右上の点数バッジが消えずに保持されます。
- **オフライン・通信エラー保護（SVGフォールバック）**：万が一、閲覧環境の通信制限などで外部画像が読み込めなかった場合でも、壊れたアイコン（リンク切れマーク）を出さず、ブランドロゴ入りの上品なミニマルSVGフレームへ自動で切り替わります。
- **不自然な改行の防止とスマホ最適化**：日本語見出しやリード文が単語の途中で不自然に切れないよう組版制御（`word-break: keep-all` / `.ib`）を施し、スマートフォン画面では商品一覧を見やすい2列グリッド、商品詳細をサムネイル切替＆スワイプ対応に最適化しています。
- **将来のECシステム移行を見据えたデータ構造**：[`js/products-data.js`](./js/products-data.js) の商品データはクリーンなJSON互換構造で整理されており、将来的に Shopify やヘッドレスECへ移行する際もスムーズに商品カタログデータを流用できます。
